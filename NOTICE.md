# NOTICE

## Independence

TabNest is an independent project. It is **not affiliated with, endorsed by, or
sponsored by** OneTab Ltd. or any other tab-manager vendor.

## No code reuse (clean-room)

TabNest was written from scratch. It reproduces _product behaviour_ — parking
tabs into lists, organising them in folders and groups, restoring them later —
because behaviour and ideas are not the thing copyright protects. It does **not**
contain, in whole or in part:

- source code or minified/bundled code from any other extension;
- icons, images, fonts, or other assets from any other extension;
- user-interface text or translations from any other extension;
- the name, logo, or trade dress of any other extension.

Development process notes, kept for auditability:

1. A behavioural specification (`docs/architecture.md`) was written first,
   describing features and user flows in our own words.
2. Implementation started from that specification only. The reference package
   inspected during research was never used as a source, and is not stored in
   this repository (it is not redistributable).
3. Every asset in `public/` is generated by `scripts/gen-icons.mjs` from code in
   this repository. There are no binary art assets of third-party origin.
4. All UI copy in `src/i18n/` was written for this project.

## Interoperability

TabNest replaces the cloud service that such extensions typically ship with. It
speaks **no** private third-party API: every byte of sync traffic goes to a
storage endpoint the user configures (or to Chrome's own `storage.sync`). There
is no migration of anyone's server-side data; the only import paths are local
files the user exports themselves.
